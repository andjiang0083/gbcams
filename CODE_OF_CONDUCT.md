# Code of Conduct / 行为准则

[EN] This is a small hobby-hardware project. Be decent: no harassment, no
dismissiveness, assume good faith. Criticism of code and design is welcome and
expected — make it specific (what breaks, on which hardware, how you reproduced
it). Maintainers may close issues or PRs that violate this.

[CN] 这是一个小型硬件爱好项目。要求很简单：不骚扰、不轻慢、默认善意。
欢迎（也期待）对代码与设计的批评 —— 但要具体：哪里坏了、什么硬件、怎么复现。
违反者，维护者可以直接关闭 issue / PR。

Report problems via a GitHub issue or the contact on my profile. / 有问题走 issue 或我主页的联系方式。
